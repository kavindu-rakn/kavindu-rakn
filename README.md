### Selected work

**[SchemaShift](LIVE_URL_SCHEMASHIFT)** — a schema migration tool with pre-commit impact analysis.
Change a data model against live records and see the blast radius before committing: which
categories are affected, how many records, and which values will not survive. Applies in a single
transaction with a rollback-able version history. Schema composition runs as a plpgsql resolver
mirrored in TypeScript, so the editor recomputes impact on every keystroke with no round trip.
234 tests. *Next.js · TypeScript · Supabase · PostgreSQL* — source available on request.

**[Hotel Tamarind Tree](LIVE_URL_TAMARIND)** — a booking platform for a boutique hotel near Yala
National Park. Eleven-model Prisma schema, availability API that prevents overlapping
reservations, a nightly job that expires abandoned bookings, and an admin dashboard for staff.
Built solo from a written specification. *Next.js · TypeScript · Prisma · PostgreSQL · Auth.js*
— source available on request.

**[Horologia](https://github.com/kavindu-rakn/Horologia)** — an exploded 3D mechanical watch
movement that disassembles as you scroll. Fourteen procedurally generated components, a raycasting
inspector showing material and function per part, synthesised ticking at 28,800 beats per hour,
and a live PBR material customiser. *Three.js · GSAP · Web Audio API · Firebase*

**[Prompta](https://github.com/kavindu-rakn/Prompta)** — a vault for AI prompts, with folders,
attachments, direct sharing between users, and one-click launch into ChatGPT, Claude or Gemini.
Interface written in plain CSS, no utility framework. *Next.js · TypeScript · Supabase*

**[Luna](https://github.com/kavindu-rakn/Luna)** — a lunar cycle visualiser. Moon phase, orbital
position and sky position in real time, with a draggable 3D moon and location-aware sky panel.
*React · Three.js · GSAP*
